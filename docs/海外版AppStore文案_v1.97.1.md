## 4. 审核备注 / Review Notes

```
「在呢+」（v1.97.1）品牌名称更新与 Apple Watch 修复版本。

主要变更：
1. 品牌名：从「打卡日记·在呢」调整为「在呢+」（App Store 展示名），主屏 App 名同步更新；代码层面（Info.plist）早已是「在呢+」。
2. Apple Watch 修复：1.97.1 修复了 Watch 端"第二天无法再次签到"的 bug，并强化手机—手表连续 / 累计天数双向同步。
3. 心率感应自动签到：检测安静期心率平稳时自动完成签到，可在 App 内关闭。

合规说明（针对审核员常见疑问）：
- 紧急求助（SOS）：完全由用户主动触发，倒计时过程中可取消；外发的求助信息仅发送给用户预设的紧急联系人，包含位置与健康档案；外发需用户主动确认。
- 守护人通知：用户主动点击「确认平安」（首页 / 健康页）即可向守护者发送平安状态；也可在「安全中心」开启"离开安全区自动确认 / 手表心跳自动确认"，确认后自动通知守护者。所有外发均基于用户的主动操作或已开启的授权。
- 位置获取：仅在用户主动触发紧急求助时单次获取，不持续追踪。
- 不替代紧急救援服务，文案已在多处明确告知。

测试账号：无需登录即可使用核心签到功能；如需完整守护圈场景测试，请用真实手机号注册，验证码通过 SMS 接收。

联系人：shan mei / meis1983@163.com

——感谢审核。
```
